# 💝 Wishlist Telegram Bot - Hello Kitty Edition

Милый Telegram бот для создания заказов вкусняшек в стиле Hello Kitty! 🎀

## 🚀 Установка

1. Установи зависимости:
```bash
cd telegram-bot
npm install
```

2. Создай `.env` файл на основе `.env.example`:
```bash
cp .env.example .env
```

3. Настрой переменные окружения в `.env`:
   - `TELEGRAM_BOT_TOKEN` - токен бота от @BotFather
   - `ADMIN_CHAT_ID` - твой Telegram chat ID (узнай у @userinfobot)
   - `MONGODB_URI` - уже настроен

## 🎮 Как получить токен бота

1. Найди @BotFather в Telegram
2. Отправь `/newbot`
3. Придумай имя для бота (например: "Wishlist Hello Kitty")
4. Придумай username (например: "wishlist_hellokitty_bot")
5. Скопируй токен и вставь в `.env`

## 🆔 Как узнать свой Chat ID

1. Найди @userinfobot в Telegram
2. Отправь `/start`
3. Скопируй свой ID и вставь в `.env`

## 🎯 Запуск

```bash
npm start
```

Для разработки с автоперезагрузкой:
```bash
npm run dev
```

## 💬 Команды бота

### Для всех пользователей:
- `/start` - Начать работу с ботом
- `/new` - Создать новый заказ
- `/orders` - Посмотреть свои заказы
- `/cancel` - Отменить текущее действие
- `/help` - Помощь

### Только для админа:
- `/admin` - Админ панель с последними заказами
- `/status [id] [статус]` - Изменить статус заказа
  - Статусы: `pending`, `processing`, `delivered`

## 🍰 Как создать заказ

1. Отправь `/new`
2. Добавляй вкусняшки по одной
3. Когда закончишь, отправь `/done`
4. Добавь комментарий или отправь `/skip`
5. Готово! 🎉

## 📊 Статусы заказов

- 💝 **Заказано** (pending) - Заказ создан
- 🛒 **В процессе** (processing) - Идешь в магазин/заказываешь
- 🎁 **Доставлено** (delivered) - Доставил вкусняшки

## 🔔 Уведомления

- Админ получает уведомление при создании заказа
- Заказчик получает уведомление при изменении статуса
