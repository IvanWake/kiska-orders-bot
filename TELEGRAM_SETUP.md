# Telegram Bot Setup

## Шаги для настройки Telegram бота

### 1. Создайте бота через BotFather

1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Сохраните токен - он понадобится для настройки

### 2. Получите свой Telegram ID (для админа)

1. Найдите бота @userinfobot в Telegram
2. Нажмите `/start`
3. Бот отправит вам ваш ID - сохраните его

### 3. Добавьте переменные окружения

Добавьте следующие переменные в Vercel или в `.env.local`:

```
TELEGRAM_BOT_TOKEN=your_bot_token_here
ADMIN_TELEGRAM_ID=your_telegram_id_here
NEXT_PUBLIC_URL=https://your-app.vercel.app
```

### 4. Установите вебхук

После деплоя приложения, откройте в браузере:
```
https://your-app.vercel.app/api/telegram/set-webhook
```

Вы должны увидеть ответ: `{"ok":true,"result":true,"description":"Webhook was set"}`

### 5. Готово!

Теперь можно использовать бота:

**Команды для пользователей:**
- `/start` - Начать работу с ботом
- `/new` - Создать новый заказ
- `/orders` - Посмотреть свои заказы
- `/help` - Помощь

**Команды для админа:**
- `/admin` - Посмотреть все заказы

**Как создать заказ:**
1. Отправь `/new`
2. Добавь вкусняшки (каждая с новой строки)
3. Когда закончишь - отправь `/done`
4. Добавь комментарий или отправь `/skip`
5. Заказ создан! Админ получит уведомление

**Уведомления:**
- Админ получает сообщение при каждом новом заказе
- Заказчик получает уведомления при изменении статуса заказа
- Админ может менять статус заказа прямо из Telegram через кнопки
